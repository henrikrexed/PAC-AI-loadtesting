## Risks & unknowns
- **R1 (sampling blindness).** Source sampling ratio = 1.0 (`Sampled: no` on this tenant → unsampled). Rare / error / retry-storm journeys are still under-represented at extraction; weights reflect the observed window only. Error-rate baselines read 0.0 because no error spans fell in the window — not a guarantee of an error-free path.
- **R2 (mean ≠ peak).** This model captures *mean* arrival over the window. No peak-envelope / 'peak vs typical' profile exists yet (separate backlog). CoV is low here so mean ≈ peak is tenant luck, not a modeled guarantee.
- **R5 (instrumentation coverage / circular ground truth).** Extraction and later validation draw from the same telemetry; shared blind spots — async fan-out, Kafka consumers, websockets, fire-and-forget — are invisible on both sides. At least one run should be cross-checked against infra metrics (CPU/connections), not telemetry alone.
- **Agentic/Conversational is the same engine as Buyer/Browser.** The split is `classify_by_terminal()` with terminal signal = `execute_tool` (AGENTIC_TOOL_PATTERNS) instead of order-terminal — zero code change from the astronomy-shop example. This is the definitive DeepSeek + sustained-load generalization the GLM / n~18 openclaw-gateway probe could not provide (see GENERALIZATION.md).
- **Weights ≈ driver TOOL_RATIO.** Agentic 0.319 / Conversational 0.681 over 301 turns (coverage 1.0) reproduce the k6 driver's TOOL_RATIO=0.30 — the skill recovers the injected behavioral mix from telemetry alone.
- **Single-step driver journey.** Each turn is one HTTP POST /request; the server-side ReAct loop (agent.turn → llm.call → chat → execute_tool×N → finalize) is internal to that request, so there is no multi-step correlates chain to carry (unlike the Buyer funnel). Baselines are per-archetype agent.turn percentiles, not route fan-out.
- **R5 cross-check.** Tools are hermetic (no outbound network); execute_tool latency reflects in-process work, not real third-party calls. A production agent with live tool backends would show heavier, more variable Agentic tails — cross-check against infra metrics on any real run.
